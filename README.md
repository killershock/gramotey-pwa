# Грамотей — PWA для iPhone

Веб-приложение, которое устанавливается на iPhone из Safari как обычное приложение:
без App Store, Xcode и Mac. Проверяет орфографию, грамматику и пунктуацию, предлагает
исправления и переписывает текст, сохраняя смысл.

## Что умеет

- **Орфография и грамматика** — онлайн-проверка через бесплатный LanguageTool
  (русский и английский, автоопределение языка).
- **Пунктуация и пробелы** — локальные правила, работают офлайн:
  - лишние пробелы и пробел перед знаком;
  - пропущенный пробел после `, ; :` и после конца предложения;
  - тире вместо дефиса и пробелы вокруг тире;
  - `...` → `…`, кавычки-ёлочки;
  - заглавная буква в начале предложения (с защитой от «т. д.» и инициалов);
  - повторы слов.
- **Подсветка прямо в тексте** по типам ошибок и карточки с контекстом.
- **Подсказки замены** — нажмите чип, чтобы исправить одно место, или «Исправить всё».
- **ИИ-редактор** — режимы как в Telegram AI Editor: «Исправить», «Перевести»,
  «Официально», «Короче», «Проще», «Дружелюбно», «Племенной», «Корпоративный»,
  «Дзен», «Библейский», «Викинг», «С матом» (18+). Смысл, имена, числа и факты сохраняются.
- **Сравнение «было / стало»** — красное удалено, зелёное добавлено.
- Тёмная тема, сохранение черновика, офлайн-оболочка, системная проверка Safari (по желанию).

## Как установить на iPhone

1. Откройте сайт в **Safari** (не в Chrome — там нет установки на домашний экран).
2. Нажмите кнопку **«Поделиться»**.
3. Выберите **«На экран “Домой”»** → «Добавить».
4. Запускайте «Грамотей» с домашнего экрана: без адресной строки, в полноэкранном режиме.

> Установка и service worker требуют **HTTPS** (или `localhost`). Локальный файл `index.html`,
> открытый двойным щелчком, не установится и не закешируется.

## Как выложить бесплатно

### GitHub Pages автоматически (без git)

В папке `gramotey-pwa/tools` лежит готовый скрипт публикации:

1. Создайте классический токен с правом **repo**:
   [github.com/settings/tokens/new?scopes=repo](https://github.com/settings/tokens/new?scopes=repo&description=Gramotey)
2. Запустите `tools\deploy-github.bat` (двойной щелчок).
3. Введите имя репозитория (Enter = `gramotey-pwa`) и вставьте токен — ввод скрыт.
4. Скрипт сам создаст репозиторий, загрузит файлы, включит Pages и откроет ссылку вида
   `https://<логин>.github.io/gramotey-pwa/`.

Токен никуда не сохраняется. После публикации его можно отозвать.
Повторный запуск скрипта обновляет файлы в том же репозитории.

### GitHub Pages вручную

1. Создайте репозиторий и загрузите туда **содержимое** папки `gramotey-pwa`
   (`index.html`, `sw.js`, `manifest.webmanifest`, `css/`, `js/`, `icons/`).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
4. Откройте этот адрес в Safari на iPhone и установите приложение.

### Netlify Drop

Перетащите папку `gramotey-pwa` на [app.netlify.com/drop](https://app.netlify.com/drop) — получите HTTPS-адрес.

### Локальный просмотр

В папке проекта выполните:

```bash
python -m http.server 8765
```

и откройте `http://localhost:8765`. На Windows можно запустить `start-preview.bat`.

## Подключение ИИ

Шестерёнка → «ИИ-редактор»:

| Сервис | Адрес API | Модель |
|---|---|---|
| **Google Gemini** (есть бесплатный тариф) | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-3.5-flash-lite` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| OpenRouter | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Свой прокси | адрес вашего шлюза | любая модель |

В настройках достаточно выбрать сервис — адрес и модель подставятся сами. Если адрес ввести
вручную без `https://`, приложение добавит его автоматически.

**Про бесплатный вариант:** у Gemini есть бесплатный тариф с лимитами (ключ создаётся в
[AI Studio](https://aistudio.google.com/apikey)). Mistral на бесплатном плане больше не выдаёт
API-ключи — там требуется Upgrade. OpenAI и DeepSeek работают по предоплате, но стоят недорого.

### Режимы переписывания

Как в Telegram AI Editor: **Исправить**, **Перевести**, **Официально**, **Короче**,
**Племенной**, **Корпоративный**, **Дзен**, **Библейский**, **Викинг**. Плюс «Проще»
и «Дружелюбно». Для перевода выбирается язык; по умолчанию — противоположный языку текста.

Ключ хранится только в `localStorage` браузера и отправляется напрямую выбранному сервису.
Если сервис блокирует браузерные запросы (CORS) или недоступен в вашем регионе, укажите
свой прокси-адрес: приложению нужен любой OpenAI-совместимый эндпоинт.

## Приватность

- Текст **не** отправляется на серверы приложения: у приложения нет своего сервера.
- При включённой онлайн-проверке текст уходит в **LanguageTool** (`api.languagetool.org`).
  Это можно отключить в настройках — локальные правила продолжат работать.
- При нажатии «Переписать» текст уходит в выбранный вами ИИ-сервис.
- Черновик и настройки лежат в `localStorage` устройства.

## Ограничения

- Публичный LanguageTool бесплатен, но имеет лимиты (примерно 20 запросов в минуту
  и 18–20 тыс. символов за запрос). При превышении приложение покажет сообщение и предложит
  подождать; для больших объёмов можно поднять свой сервер LanguageTool и указать его адрес.
- Онлайн-проверка обрабатывает первые **18 000 символов** — локальные правила работают
  по всему тексту.
- Локальные правила пунктуации — эвристики: сложные запятые (придаточные, вводные слова)
  намеренно не трогаются, чтобы не портить текст.
- Прямые запросы к ИИ из браузера зависят от CORS конкретного сервиса.

## Структура

```
├── index.html
├── manifest.webmanifest
├── sw.js
├── start-preview.bat
├── css/styles.css
├── js/
│   ├── app.js          состояние, подсветка, карточки, диалоги
│   ├── rules.js        офлайн-правила пунктуации и пробелов
│   ├── languagetool.js онлайн-проверка орфографии и грамматики
│   ├── ai.js           запросы к OpenAI-совместимому API
│   ├── diff.js         сравнение «было / стало»
│   ├── store.js        настройки и черновик в localStorage
│   └── utils.js        мелкие помощники
├── icons/
└── README.md
```

После изменения файлов поднимите версию `CACHE_NAME` в `sw.js` — иначе service worker
продолжит отдавать закешированную старую версию.

## Что можно добавить

- Свой словарь исключений (имена, термины, бренды).
- Экспорт исправленного текста в файл.
- Голосовой ввод через Web Speech API.
- Собственный сервер LanguageTool в Docker — без лимитов и без отправки текста третьим лицам.
